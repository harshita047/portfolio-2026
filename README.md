# Harshita's Portfolio

A personal portfolio website built with HTML and CSS.

## 🛠️ Built With
- HTML5
- CSS3 (Flexbox + Grid)

## 📌 Features
- Responsive navbar with resume button
- Hero section with photo
- Skills badges
- Projects section
- Contact section

## 🚀 How to Run
Open `index.html` in any browser.
