# 🌐 Harshita's Portfolio
A personal portfolio website built with HTML, CSS, and JavaScript — showcasing my projects, skills, and contact information.

🔗 **Live Site:** [[harshita047.github.io/porfolio-2026](https://harshita047.github.io/porfolio-2026)](https://porfolio-2026-omega.vercel.app/)

## 🛠️ Built With
- HTML5
- CSS3 (Flexbox + Grid)
- JavaScript (Vanilla)
- Font Awesome Icons

## 📌 Features
- **Responsive Design** — works on desktop and mobile
- **Dark Mode Toggle** — switch between light and dark theme
- **Hamburger Menu** — mobile-friendly navigation
- **Smooth Scroll** — navbar links scroll smoothly to sections
- **Project Cards** — showcase projects with live and GitHub links
- **Contact Section** — direct links to email, LinkedIn, and GitHub
